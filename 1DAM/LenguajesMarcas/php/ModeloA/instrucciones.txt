EJERCICIO PRÁCTICO
Se debe crear una aplicación Web para gestionar la tabla de los libros de una base de datos
de una biblioteca. La aplicación debe permitir listar, crear, editar y eliminar registros en una
base de datos MySQL. Cada producto tendrá los siguientes campos:
• id: entero autoincremental y clave primaria.
• titulo: texto obligatorio.
• autor: texto obligatorio.
• precio: número decimal obligatorio, mayor que 0.
• stock: número entero obligatorio, mayor o igual que 0.
• fechaCreacion: Tipo fecha timestamp. Almacenamiento automático.
