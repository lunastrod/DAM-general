valor de los tres lados de un triángulo facilitados, indicar si el triángulo es equilátero, isósceles
o escaleno.

DECLARAR lado1
DECLARAR lado2
DECLARAR lado3
LEER lado1
LEER lado2
LEER lado3
IF lado1==lado2==lado3
    MOSTRAR "equilátero"

    MOSTRAR "escaleno"

Ejercicio 3. Especificar un algoritmo con pseudocódigo que se encargue de calcular y mostrar
la suma de los n primeros números naturales.

DECLARAR n
DECLARAR resultado
LEER n
WHILE n>0
    resultado=resultado+n
    n=n-1
MOSTRAR resultado
END


Ejercicio 4. Especificar un algoritmo con pseudocódigo que se encargue de calcular y mostrar
la suma de los diez primeros números entre 1 y 1000 que sean divisibles por uno dado.

DECLARAR divisor, contador, numerosSumados, resultado, CANTIDAD, MAXIMO
CANTIDAD=10
MAXIMO=1000
LEER divisor
contador=0
numerosSumados=0;
resultado=0;
WHILE contador <MAXIMO and numerosSumados<CANTIDAD
    IF contador%divisor==0
        resultado=resultado+contador
        numerosSumados=numerosSumados+1
    contador=contador+1
PRINT resultado

Ejercicio 5. Realiza el pseudocódigo para el siguiente programa: Un aspirante a un empleo,
realiza un test de capacitación. Se obtiene la siguiente información: cantidad total de
preguntas que se le realizaron y la cantidad de preguntas que contestó correctamente. El
programa solicita los dos datos por teclado e informa el nivel según el porcentaje de
respuestas correctas que ha obtenido sabiendo que:
• Nivel sobresaliente: Porcentaje>=90%
• Nivel notable: Porcentaje>=75% y <90%
• Nivel suficiente: Porcentaje>=50% y <75%
• Nivel insuficiente: Porcentaje<50%

DECLARAR totalPreguntas
DECLARAR preguntasCorrectas
LEER totalPreguntas
LEER preguntasCorrectas
IF totalPreguntas/preguntasCorrectas>=0.9
    PRINT "sobresaliente"
IF totalPreguntas/preguntasCorrectas>=0.75
    PRINT "notable"
IF totalPreguntas/preguntasCorrectas>=0.5
    PRINT "suficiente"
ELSE
    PRINT "insuficiente"
