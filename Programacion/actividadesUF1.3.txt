Escribe el pseudocódigo correspondiente al
siguiente algoritmo que indica, a partir de un número
dado, si éste es par o impar.
1. Pedir el número
2. Dividir el número dado entre 2 y recoger el resto
3. Comprobar si el resto es 0 en cuyo caso se
indicará que el número es par o, si por el
contrario, el resto es diferente de 0, se indicará
que es impar.


    LEER n
    r=n%2
    if r == 0
        mostrar "es par"
    else
        mostrar "es impar"
    endif
